About

How the model works

A single Decision Tree classifier predicts one internship category from education, domain interest, career goal, project count, certification count, experience level and skill count.

Recommendations are ranked separately by required-skill overlap plus a bonus when the listing matches the predicted category. This is not a second ML model.

The training data is synthetic and shows how the pipeline works. It does not prove real-world hiring accuracy. Always verify the employer’s official page.

Format guide

Accepted files: CSV, TSV, TXT (comma, tab or semicolon separated), Excel (.xlsx, .xls), JSON (a list of students, or an object containing one) and XML. Maximum size 150 MB, up to 200,000 rows.

  • education: B.Tech CSE, B.Tech IT, B.Sc Computer Science, BCA, MCA, B.Tech ECE, B.Tech AI & DS
  • domain_interest: Data Analytics, Machine Learning, Python Development, Web Development, Software Testing, Cybersecurity, Cloud Computing, Product Management
  • career_goal: Data Analyst, ML Engineer, Python Developer, Web Developer, QA Engineer, Security Analyst, Cloud Engineer, Undecided
  • experience_level: None, College project, Internship, Freelance
  • skills: comma separated, e.g. “Python, SQL, Pandas”
